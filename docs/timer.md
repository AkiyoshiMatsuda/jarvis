# タイマー機能

2026-10-10。ファイル検索より先に、音声・文字入力から操作できるタイマーを追加。

## 使い方（cmd）

```bat
cd /d D:\Jarvis
start-jarvis.cmd
```

文字入力で「3分測って」「1分30秒のタイマーをかけて」「タイマーを1分半セットして」と送信する。
音声の場合は呼びかけてから同じ内容を話す。タイマー操作はAIモデルを使わず、認識された文字列を直接処理する。
「タイマーの残り時間を教えて」「タイマーを止めて」でも操作できる。

- 同時に1件、1秒〜24時間。動作中のタイマーは上書きせず、停止してから新しく設定する。
- 画面上部に残り時間を時:分:秒で表示。トレイのツールチップにも残り時間を表示。
- 「タイマーを停止」で解除。終了すると表示が「時間になりました」に変わり、「確認」で消去できる。
- 終了時は画面の表示・タスクバー点滅・Windows通知で知らせる。Windows通知自体は無音。
  別途JARVISが短い通知音を鳴らす。再生後に約5秒空けて、停止するまで繰り返す。
  「アラートを停止」で解除できる。通知音量は「応答音量」に従い、消音なら画面表示のみ。
- 音声入力・文字起こし・回答生成・読み上げ中は、それらを止めず通知音だけを待機させる。
  通知音を鳴らす際はマイクを一時停止し、再生終了後700 ms待って元の監視設定へ戻す。
- 「新しい会話」、会話消去、監視停止、ワーカーの再試行ではタイマーを解除しない。
- ロック中はカウントを継続し、通知音は解除後に回す。スリープ中は音を鳴らせず、復帰時に期限を確認する。
- ×でトレイに隠しても継続する。JARVISを完全に終了した場合は解除され、再起動後には復元しない。

## 実装と制限

タイマーはメインプロセスで締切時刻を保持し、250 msごとに確認する。
毎秒の減算ではなく締切と現在時刻との差を使うため、処理の遅延やスリープ後も残り時間を再計算する。
PCの時計を手動変更した場合はその差の影響を受ける。
残り表示は約1秒ごとに更新。通知音は専用の音声経路で、会話の読み上げとは同時再生しない。
通知音の再生には5秒の上限があり、失敗しても終了表示を残す。
Windowsの通知設定・集中モードなどによりトーストが見えない場合も、アプリ内の終了表示は残る。

## 検証

Node自動テスト50件成功。数字・漢数字・全角・複合時間、範囲外、上書き拒否、取消、
遅れた期限確認・一度だけの終了通知を含む。
同梱版ではタイマー操作がAIを呼ばないこと、会話リセット後の継続、回答待ちとの並行動作、
回答完了後の通知音、ロック中の保留、消音を確認した。
読み上げ中にも通知音が重ならないこと、通知音の前後でマイク監視を停止・再開すること、
通知中の「監視を停止」がそのまま維持されることも同梱版で成功した。
証跡は `validation/timer/packaged.json` と `preview.png`。
既存の質問入力取消・ワーカー復旧・ロック復帰・単一起動・親終了時の子終了も回帰試験に成功。
結果は `validation/timer/regression.txt`。
