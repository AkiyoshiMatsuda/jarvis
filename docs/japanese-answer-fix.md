# 日本語回答への中国語混在の修正

2026-10-09。ユーザーから「何か关于芒果的建议吗」と出力されたとの報告。
文字エンコーディングの問題ではなく、ローカルモデルが中国語を混ぜて生成する問題として再現した。
合成した会話履歴に当該表現を入れると、日本語指示の強化だけでは同様の文末が再発した。

## 変更

- 挨拶・文末の問いかけを含め自然な日本語で統一する指示を追加。
  履歴内の外国語表現をまねしないこと、不要な追加質問を付けないことも指定。
- 今回の「关于」「建议」「吗」など、中国語混在の手掛かりが回答にあれば一度だけローカルで校正する。
  校正時には元の会話履歴を再送せず、回答候補と校正専用の指示を使う。
- 校正後も混在が検出されたら日本語のエラーを表示し、その回答は表示・読み上げ・履歴追加に進めない。
  全体の100秒制限、取消、履歴リセットによる遅延応答の破棄は維持。
- ユーザーが明示的に依頼した中国語への翻訳や引用、コードなどは区別する。
  漢字全般を禁止する処理は行わない。

これは限定的な文字列の検出とモデルによる校正であり、あらゆる外国語混在を検出する言語判定器ではない。
校正には追加の回答生成時間がかかる。正しい日本語・内容の完全な保証はできない。
修正版の起動で古い会話履歴は消える。再発時は「新しい会話」で文脈をリセットできる。

## 検証

自動テスト45件成功。検出・一度だけの校正・校正失敗時の履歴保護・校正途中の取消を含む。
実モデルでは挨拶、果物の記憶と想起、混在した履歴に対する礼と想起の5件で、検証対象の中国語表現が残らないことを確認した。
校正後に英語の一般名詞が残る例もあり、完全な日本語への統一は引き続き評価が必要。
証跡は `validation/japanese-answer-fix/local-model.json` に保存した。
同梱版へ更新し、会話の継続・リセット・ロック時消去・読み上げ・途中停止の統合試験も成功。
結果は `validation/japanese-answer-fix/packaged.json`。
