# 天気予報

## 使い方

`start-jarvis.cmd` で更新済みの同梱版を起動します。「天気予報」欄で市区町村名を入力し、「地域を検索」を押して候補を選択してください。日本国内に対応します。日本語で見つからない場合は `Osaka` などのローマ字表記も試してください。APIキーやアカウント登録は不要です。選択した地域は次回起動時にも引き継ぎます。

音声・文字の両方で、次の質問ができます。

| 質問例 | 回答 |
| --- | --- |
| 今日の天気を教えて | 今日の天気、最高・最低気温、最大降水確率 |
| 明日は雨？ | 明日の予報と傘の目安 |
| 明後日の気温 | 明後日の予報と気温 |
| 今の天気 | 現在の予測値、気温・体感気温・風速 |
| 週間天気／今週の天気 | 今日から7日間の予報 |
| 傘は必要？ | 今日1日全体の予報に基づく目安 |

設定済みのIchiroなど、通常の読み上げ音声・速度・音量で読み上げます。長い週間予報は「読み上げを停止」で止められます。取得中は「入力を取り消す」で中断できます。タイマーは取得中も進み、通知音は回答・読み上げの終了を待ちます。

## 予報の意味と保存範囲

- 予報は [Open-Meteo](https://open-meteo.com/en/docs)、地域データは [GeoNamesを使用する地域検索API](https://open-meteo.com/en/docs/geocoding-api) です。
- 日本時間で表示します。「今週」はカレンダー機能と異なり、今日から7日間です。現在の天気もモデルによる予測値で、実測値ではありません。
- 日別天気はその日の最も強い天候、降水確率は1日の最大値です。傘の案内も残り時間だけの予報ではありません。
- 予報は最大10分間メモリ内で再利用し、地域変更・日本時間の日付変更で再取得します。表示する「取得」は取得時刻です。通信失敗時に古い予報を新しい予報として回答しません。
- 地域検索では検索語、予報取得では選択地域の緯度・経度をOpen-Meteoへ送信します。音声・会話履歴は送りません。天気の質問・回答はOllamaや会話履歴に渡さず、地域名・予報本文を診断ログに記録しません。
- 選択地域はPC内の `%APPDATA%\jarvis-local\settings.json` に保存されます。「地域を解除」で削除できます。この設定ファイルはGit公開対象外です。GPSやIPによる地域の自動推定は行いません。
- インターネット接続が必要です。未設定、通信障害、取得できない日の場合は画面に案内を出します。
- 現時点では地域は1つです。質問中の地域指定、時間別予報、来週以降、警報通知は未対応です。

無料APIは個人・非商用向けです。再配布や商用利用の際は [Open-Meteoの利用条件](https://open-meteo.com/en/terms) を確認してください。予報データはCC BY 4.0、回答・画面に提供元を表示します。
