# 無料の出典付きWeb検索

## 使い方

更新済みのJARVISを起動し、「富士山の標高を調べて」「最新の宇宙開発ニュースを検索して」のように質問します。APIキー・アカウント・課金契約は不要です。ネット接続は必要です。

「設定 → Web検索」で、自動／常に検索／オフを選べます。以前オフにしていた場合は自動に変更してください。Brave APIは呼び出しません。以前のBraveキーがPC内にある場合だけ、削除ボタンを表示します。以前のBrave契約の変更・解約はサービス側で行ってください。

## 検索方式

[DuckDuckGoが提供するHTML版](https://duckduckgo.com/duckduckgo-help-pages/features/non-javascript/)の検索ページから結果を取得します。公式の有料APIではなく通常の検索ページを利用するため、アクセス制限・CAPTCHA・HTML変更により取得できなくなる場合があります。その場合はエラーを案内し、制限回避や自動再試行は行いません。

質問文だけを検索語としてDuckDuckGoに送ります。会話履歴・カレンダー・音声・位置情報は付加しません。検索文に含めた個人情報は送られるので、秘密情報を質問に含めないでください。キー・パスワードらしい一部の表記は送信前に検出しますが、完全な検出ではありません。

1回の質問につき検索ページを1回取得し、広告・重複・不正なURLを除いた最大5件を使います。「今日・速報」は日単位、「最新ニュース」は週単位の絞り込みを要求しますが、実際の公開日・最新性は出典で確認してください。

## 回答と出典

要点抽出はPC内のOllamaで行います。最大3点を選び、検索結果の説明文に実在する文章かを検査します。URLは検索結果から取得し、AIに生成させません。回答の番号と出典の番号が対応し、出典タイトルを押すと既定のブラウザーで元ページが開きます。検索結果の抜粋も展開して確認できます。

リンク先本文は自動取得しません。今回の機能は検索結果の説明文からの要点抽出で、本文全体の要約ではありません。画面に示す取得時刻はページの公開・更新日時ではありません。結果の存在だけで正確性を保証するものではありません。

Ollamaの抽出が失敗しても取得済みの出典と抜粋を表示します。検索自体が失敗した場合に、未検索のAI回答へ黙って切り替えることはありません。

## 判定と操作

- 自動判定：最新・ニュース・料金・営業時間・発売・おすすめ・比較・仕様・使い方などの語や、検索・出典・公式サイトを求める表現で検索します。語句によるルールなので、検索されない場合は「○○を検索して」と明示してください。
- 「検索せずに答えて」はローカル回答を優先します。タイマー・カレンダー・設定地域の天気は専用機能が優先です。
- 「それの価格」などの省略は対象名を含めて聞き直してください。会話履歴は検索に送信しません。
- 検索中は取り消し可能です。遅れて返った結果を表示せず、タイマーは継続します。読み上げを止めても出典は残ります。
- 検索結果はメモリ内だけに保持し、会話の消去・ロック・終了などで消去します。質問・結果本文を診断ログに保存しません。
