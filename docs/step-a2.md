# Step A-2 — 日本語のローカル文字起こし

実装日: 2026-10-09。質問入力の実装に、入力終了後の日本語文字起こしと結果表示を追加。
2026-10-10追記: 現行同梱版は大型日本語モデルに更新済み。以下は初期実装の記録であり、現在のモデルと検証結果は [音声認識の改善](stt-number-improvement.md) を参照。
本人の発声による質問入力・認識精度は、ユーザーが可能なタイミングで検証する。

## 動作

1. 「Hey Jarvis」または「質問入力を開始」で入力を開始。
2. 固定の返事の後、「質問を聞いています」と表示されたら話す。
3. 無音または約15秒の上限でマイクを閉じ、「文字に変換しています」と表示。
4. 完了すると待機へ戻り、「聞き取った内容」を表示。AIによる回答はまだ行わない。

発話なしの場合は文字起こしせず待機へ戻る。認識結果が空の場合は再入力を案内する。
環境音も発話判定を通過し得るため、認識結果は正確な発話の保証ではない。
入力上限で区切られた音声は、その範囲だけを文字起こしする。
認識文は画面の「消去」、次の質問入力開始、ロック・スリープ、アプリ終了で破棄する。
文字起こし中も「入力を取り消す」「監視を停止」で中断できる。

## 採用構成とデータ

- Vosk 0.3.45と日本語小型モデル `vosk-model-small-ja-0.22` を同梱。
- モデルは約48 MBのダウンロード。小型モデルをまず採用し、本人の声での精度評価後に継続判断する。
- APIキー・従量課金は不要。アプリの通常動作ではモデル取得を行わず、明示的なローカルパスを使用する。
- マイク音声はメモリと親子間の匿名パイプだけで受け渡し、ファイル保存・外部送信をしない。
- 認識文はメモリと画面のみで保持し、設定や診断ログへ書き込まない。録音履歴・会話履歴は作らない。
- 各モデルファイルのSHA-256を `models/stt-manifest.json` に記録し、読み込み時に検証。
  これは取得後の変更検知であり、提供元の署名検証ではない。
- 文字起こしは入力ごとに別プロセスで実行。待機中はモデルを常駐させず、初回を含め読み込み時間がかかる。
- ワーカーは文字起こし中も停止・pingを受け付ける。処理の上限45秒、Electron側の結果待ち上限60秒。
- 取消時は処理プロセスを終了し、取消前の結果は画面に反映しない。親終了も監視する。
- 無音判定・15秒の入力上限はStep A-1と同じ。今回はSTTのみで、LLM・ファイル操作等は追加していない。

## 起動（cmd）

```bat
cd /d D:\Jarvis
start-jarvis.cmd
```

更新済み同梱版では追加のインストールは不要。開発環境を再構築する場合のみ:

```bat
cd /d D:\Jarvis
.\.venv\Scripts\python.exe -m pip install -r requirements-build.lock.txt
.\.venv\Scripts\python.exe prepare_stt.py
npm run package
```

`prepare_stt.py` のみネットワークでモデルを取得する。既存のマニフェストがある場合は再取得せず検証する。

## 検証と限界

- Node 19件成功: 文字起こし状態、取消後の結果無視、結果待ち上限、ログからの認識文除外を含む。
- Python 20件成功・実マイク明示試験1件スキップ: 実日本語モデル、合成PCMの入力から結果まで、
  無音、取消、クラッシュ、タイムアウト、親終了後の子終了を含む。
- 日本語の既存TTS音声を使った機能確認であり、本人の発声に対する認識率評価ではない。
  小型モデルの誤認識・表記ゆれ・語間の空白は残る。句読点の整形・確定前の途中表示は対象外。
- 本人の発声、実環境の雑音、認識率・応答時間の受け入れ判定、追加機能を含む長時間試験は未実施。
- 同梱版STTで既存TTS「はい、何でしょう？」を入力し「はい 何 でしょ」を取得。
  最終確認ではプロセス起動・モデル読み込み込みで約2.71秒（1試行、性能保証ではない）。
- 同梱画面では別の固定テスト文を使い、表示・消去とログ非記録を確認。
  `validation/step-a2/packaged.json`、`preview.png` に証跡を保存。
- 最終同梱版の既存機能回帰試験も成功。短時間の実マイク取得による入力終了・取消・監視停止、
  復旧、ロックイベント注入、単一起動、親終了時のワーカー終了を確認。
  本人発声試験の代替ではない。証跡は `validation/step-a2/regression.txt`。
